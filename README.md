# 🦊 RMX3624-GKI-5.4-Kernel (`RedFox-Ultimate`)

> **Флагманское кастомное GKI-ядро (`Linux 5.4.256`) для смартфонов Realme C30 / C33 (`RMX3624`, чипсет Unisoc T612 / `ums9230`) с нативным драйверным бустом пиковой яркости экрана до `4095 / 4095`, встроенным `KernelSU + SuSFS` и полной поддержкой современных Android 13 – Android 17 GSI.**

## ✨ Ключевые особенности (`rev18-Ultimate`)

| Компонент | Реализация в ядре RedFox | Эффект на устройстве |
| :--- | :--- | :--- |
| **Яркость дисплея** | Нативный C-патч в драйвере `sprd_oled` (`bdev->props.brightness`) | Убирает системную обрезку GSI (`3773`) и выдаёт честные **`4095 / 4095`** при максимальном положении ползунка в шторке. |
| **Root и скрытие** | Встроенный **`KernelSU`** + патч **`SuSFS`** на уровне ядра | Полноценный рут без модификации системного раздела и надёжное скрытие от банковских приложений. |
| **Камера и видео** | Фиксы DMA/ION-буферов + поддержка модуля **`RedFox-Optimizer-v1.4`** | Стабильная работа фото- и видеосъёмки в современных **Android 16 / 17 GSI**. |
| **Сеть и интернет** | Алгоритм **`TCP BBR`** + планировщик пакетов **`CAKE`** | Снижение задержек (пинга) и стабильная скорость в мобильных сетях 4G и Wi-Fi. |
| **Память и CPU** | **`ZRAM ZSTD`** (3 ГБ) + регулятор частот **`schedutil`** | Плавная работа интерфейса и многозадачности даже на моделях с 3 / 4 ГБ ОЗУ. |
| **Версия ядра** | Чистая строка **`5.4.256-RedFox-rev18-Ultimate+`** | Аккуратное отображение в настройках Android, KernelSU и **RedFox Manager**. |

## 📦 Что входит в актуальный релиз (`Releases`)

1. **`boot_redfox_rev18_signed.img`** — готовый к прошивке образ раздела `boot` (`header_version 4`, 64 МБ), подписанный ключом **AVB 1.0 (`SHA256_RSA4096`)**.
2. **`Image.gz`** — чистое сжатое ядро для разработчиков и ручной перепаковки.
3. **`RedFox-Optimizer-v1.4.zip`** — системный модуль для KernelSU / Magisk (активирует `TCP BBR`, `vm.swappiness=100`, линейную шкалу яркости GSI и программные видеокодеки).

## 🛠️ Инструкция по установке

### Способ 1 — Автоматический через `RedFox-Flasher` (рекомендуется)
Используйте консольную утилиту **[RedFox-Flasher](https://github.com)** для Arch Linux / Linux:
- **Пункт `3`:** Сделайте резервную копию разделов (`boot`, `vendor_boot`, `vbmeta`).
- **Пункт `4` или `8`:** Прошейте **`boot_redfox_rev18_signed.img`** через Fastboot или BROM (`spd_dump`).
- **Пункт `9` (Цикл чистой установки GSI):** Если вы ставите новую GSI-прошивку и хотите сделать `Wipe Data / Factory Reset` в стоковом Recovery, выберите пункт `9` — флешер сам временно вернёт совместимый boot для входа в Recovery, а после очистки памяти и прошивки GSI вернёт ядро **`RedFox rev18`** и запустит систему.

### Способ 2 — Ручная прошивка через `Fastboot`
1. **Сделайте полный бэкап** разделов `boot_a`, `boot_b`, `vendor_boot` и `vbmeta`.
2. Скачайте **`boot_redfox_rev18_signed.img`** и **`RedFox-Optimizer-v1.4.zip`** со страницы [Releases](https://github.com).
3. Переведите смартфон в режим **`Bootloader (Fastboot)`**:
   ```bash
   adb reboot bootloader
   ```
4. Прошейте подписанный образ ядра сначала в активный слот **`boot_a`** (оставив рабочий образ в `boot_b` в качестве резервной страховки) и перезагрузите устройство:
   ```bash
   fastboot flash boot_a boot_redfox_rev18_signed.img
   fastboot reboot
   ```
5. После загрузки Android откройте **KernelSU Manager** → **Модули** → **Установить из хранилища** → выберите **`RedFox-Optimizer-v1.4.zip`** и перезагрузите смартфон.
6. *(Опционально)* После успешной проверки работы системы, камеры и яркости вы можете продублировать ядро и во второй слот (`fastboot flash boot_b boot_redfox_rev18_signed.img`).

## 🔗 Экосистема проектов RedFox для RMX3624

- 📱 **[RedFox-Manager](https://github.com)** — нативное Android-приложение на Kotlin для мониторинга температуры, напряжения батареи, яркости дисплея (`4095`), управления ZRAM / TCP BBR и перезагрузки в Fastboot / Recovery.
- ⚡ **[RedFox-Flasher](https://github.com)** — интерактивная CLI-утилита для диагностики, бэкапов, прошивки ядра и цикла чистой установки GSI.
- 🛠️ **[Red-Fox_RECOVERYRMX3624](https://github.com)** — кастомное рекавери на базе OrangeFox 14.1 для Realme C33 (`RMX3624`).
